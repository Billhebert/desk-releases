# Desk - Releases

Instaladores do Windows para o **Desk** (cliente remote desktop custom).

## Baixar

- 1.5.4: [desk-1.5.4-x86_64.exe](https://github.com/Billhebert/desk-releases/releases/download/1.5.4/desk-1.5.4-x86_64.exe)
- 1.5.1: `desk-1.5.1-x86_64.exe`

O proprio Desk verifica este repositorio (`releases/latest`), compara a tag com a versao instalada e oferece a atualizacao.

## Convencoes

- Tag da release = versao (ex. `1.5.4`), sem prefixo `v`.
- O asset do instalador deve ser nomeado `desk-<versao>-x86_64.exe` (x86/arm64 -> `arm64`).
