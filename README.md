# Desk - Releases

Instaladores do Windows para o **Desk** (cliente remote desktop custom).

## Baixar

- 1.5.1: `desk-1.5.1-x64.exe`

O proprio Desk ja verifica este repositorio (`releases/latest`), compara a tag com a versao instalada e oferece a atualizacao.

## Convencoes

- Tag da release = versao (ex. `1.5.1`), sem prefixo `v`.
- O asset do instalador deve ser nomeado `desk-<versao>-x64.exe`.
